# くるま ずかん

車の図鑑アプリです。iPhone のブラウザで開き、ホーム画面に追加して使います。

- 車を3Dモデルで表示します（指で回せます）
- 車ごとに写真を追加できます（写真はその端末のブラウザの中だけに保存されます）
- エンジン音は、音が見つかった車だけ再生ボタンが出ます

## 車を1台ふやすとき

1. 3Dモデル（.glb）を `models/` に、一覧用の絵を `posters/` に置く
2. `cars.js` の `CARS` に1台分を足す（作者名・ライセンスも書く）

3Dモデルは、Sketchfab から落としたものを gltf-transform で圧縮して置いています。

## 素材の出どころ

各モデルの作者・ライセンスは `cars.js` と、アプリ内の「このアプリについて」に書いています。
